# 源码范围与本地清理

openAgent 是使用 K-brain 的本地桌面应用。Git 中保留产品源码、开发测试、构建配置、依赖锁、资源及许可证。

## 已退出产品源码的内容

- 独立 `agent-gateway` 和 WebUI 应用、远程同步测试设施。
- 原生宿主中未注册的 Gateway、隧道、SFTP、语音输入、WebDAV 服务实现。
- 已断开桌面引用的远程/SSH/语音设置页面，以及部分退役的图像工作台视图。
- 历史上游方案、评审、验收截图、部署配置和不适用于本产品的自动任务。
- 移动端图标和旧品牌矢量图。

## 必须保留的边界

桌面仍需要本地终端、浏览器操作、MCP、网络代理、模型请求、更新下载和工具审批。不能按 `remote`、`ssh`、`gateway` 等单词全局删代码：历史配置迁移、协议字段和工具结果兼容仍可能使用这些名称；它们不构成远程控制入口。各平台的原生适配和必要图标也不能仅按当前开发机器删除。

测试已移除对独立 WebUI 源码的依赖，桌面和共享逻辑的回归检查继续保留。`check:source-scope` 检查 Git 跟踪的目录范围，防止把退役应用、依赖、构建产物或用户数据重新提交。

## 本地清理

可再生的 `target`、`dist`、前端 `dist`、临时验证检出、日志和截图可删除，下一次构建会重新生成。保留 `node_modules` 和供开发使用的 K-brain 依赖。清理不删除用户正式数据、开发预览数据或仓库外的发布密钥；临时目录中发现的真实数据副本应先移至仓库外的恢复目录。

Git 使用普通提交记录这次精简，历史提交及 v0.1.0 标签保留，便于审计和恢复；这不是重写 Git 历史。

## 本轮验证范围

桌面与共享 UI 类型检查、生产前端构建、Rust 工作区（含测试目标）编译检查、内置 Skills 校验和构建脚本测试通过。完整桌面前端测试发现的退役功能预期已调整，并对受影响用例重新验证；会话列表、删除、运行中状态等桌面断言保留。

仍有两个既有检查问题，本轮没有扩大产品修改范围去隐藏它们：侧栏按钮触控热区断言与已有 `static after:hidden` 样式冲突；启动 CSS gzip 大小约 83.8 KiB，超过原 71.1 KiB 预算。这不影响已通过的编译检查，但不能声称全部质量门禁通过。

本地旧验证记录和预览构建已清理，文档内早期 `.openagent-validation` 路径属于历史验收记录；当前维护日志在用户 LocalAppData 的 `openAgent/maintenance/20261127-source-cleanup`。真实数据备份移至 `openAgent/recovery/20261127-source-cleanup`。受工具永久删除限制，构建及临时产物使用 Windows 回收站清理，可恢复；占用空间在回收站清空后才释放。
