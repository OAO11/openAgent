# openAgent v0.1.0

首个 Windows x64 安装版本，基于 LiveAgent 桌面和 K-brain 本地后端。

- 使用 openAgent 紫青色 Logo，统一应用、安装包、快捷方式和托盘图标。
- 数据、聊天记录、设置、界面缓存统一存放在安装目录的 `data` 文件夹。
- 更新来源为 OAO11/openAgent，使用 openAgent 专用密钥验证更新包。
- 本机开发工作台，内置开发流程 Skills、Hooks、提示词和可选主题。
- 安装窗口默认为 1159 × 857，工作台右侧默认收起。

安装到当前用户可写的目录，例如 `D:\software\openAgent`。原地更新保留 `data`；卸载时只有明确勾选删除应用数据才清理 `data`。开发预览的 `%USERPROFILE%\.openagent` 数据不会自动搬移，请通过备份导入迁移所需内容。

本包带有自动更新验证签名；尚未配置 Windows Authenticode 发布者证书，Windows 可能显示“未知发布者”。安装包包含 K-brain 后端；WebView2 由系统提供，缺少时安装程序需联网安装运行时。
